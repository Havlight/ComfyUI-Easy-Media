# 成人与亲密互动分镜

在 [craft.md](../craft.md) 镜头分工（胸上表情反应近景 ↔ 脸部出画的局部接触特写）的基础上，补充亲密题材的写法。

## 分镜与构图

- 跳过进入与生理变化过程：脱衣、掏取、生理状态变化与对准进入的瞬间极易变形融化，一律在切镜（`shot`）中省略，直接从已经建立稳定接触、支撑面固定的姿势开拍，并写明身体压在哪个家具或平面上（床垫、沙发、桌面）。
- 遮挡剔除：背面后入不回头时不写正面胸部与五官；脸部出画的局部特写（如腰臀与大腿近景）删掉所有表情与视线描述，集中在肢体张力、支撑点与接触细节。
- 第一人称低头视角（POV）不能只让局部部位从画面底边凭空探出（缺乏连接极易弯折或比例失真），须连同可见的下腹、大腿根部或扶握的手一起写出；需要看清局部结构时，用自然语言写明清晰的轮廓与连接根部。

## 多人与动作

- 双人以上服务或接触同一对象时，写明共用画面中央单一主体，并分配左右不同的具体动作（如左者扶握根部、右者贴近辅助），不笼统写两人同时做同一动作（易导致目标部位重复生成）。多男同场时在体型、肤色、发型或眼镜配件上拉开反差。
- 三人以上交缠或双人近距离协作，纯 `ref` 模式重绘首帧容易多长肢体；若手边已有比例相符、结构无误的单格姿势图且该段不需绑定音色参考，可用 `default` 模式作首帧驱动稳定节奏动作，胸上台词与反应镜头再用 `ref` 模式绑定音色。

## 表演、声音与状态

- 避免狂乱、极度失神等夸张词汇（H3 易把五官画崩），改用具体克制的面部细节（如浅笑、咬下唇、眼神游移、轻喘）。
- 接吻或口部被占用期间不放 `<d>` 台词或人声（否则模型强行张嘴发话会导致穿模或多长部位），呼吸、鼻息与接触声一律写在 `overall_soundscape`。
- 服装剥离阶段（穿戴整齐 → 半脱掀起 → 仅留袜饰）、汗水、湿发与体液残留须在后续段落持续写出；若环境装有 `adult-kb` 技能可按需查阅体位支撑几何，但须全部转译为纯英文自然语言，不把底线标签或词库编号写进提示词。
