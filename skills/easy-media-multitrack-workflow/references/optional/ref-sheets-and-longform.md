# 多格参考板、短链延续与长片巡检

在 [craft.md](../craft.md)（及需要时的 [modules/type-adult.md](../modules/type-adult.md)）基础上，按专案复杂度灵活选用，由 Agent 依画面风险判断。

## 角色设定板与合并通道

- **按露脸需求区分角色板拼法**：
  - **核心露脸角色**（排最前顺位如 `<Picture 1>`）：用「高解析脸部特写 + 正面全身（遮住小脸）+ 背面全身」拼成单张设定板——遮住全身格的小脸可避免低解析五官干扰特写大脸。
  - **非露脸配角／POV 角色**：用「正面全身（遮头脸）+ 背面全身」，省去不入镜的正脸资讯。
  - **局部收尾镜头撤板**：只拍手腕、衣角或平静局部的镜头，即使该角色在场也撤掉全身裸体设定板，避免模型强行塞入多余身体局部。
- **合并参考通道**：动线相连的两个空间（如室内与阳台、走廊与房间）或穿脱前后的对照状态，可横向拼成单张同画幅通道，节省参考槽位并帮助跨空间／跨状态衔接。
- **按遮挡增删局部外观词**：局部生理或服饰末端细节只在外部可见时写出；进入紧密贴合的坐姿、骑乘或交叠姿态时，删去被遮挡的末端外观描述，改写骨盆贴合与家具支撑面，防本该遮挡的部位画到体外。

## 参考图选配与构图控制

遵循「一图一职」，光影氛围直接由环境空镜与文字控制（不单独挂光影图以防画面污染）。Agent 可按画面风险自由判断或依用户要求，由简到繁选配：

1. **基础组合（默认主力）**：只挂「角色设定板 + 环境空镜」（有跨镜一致需求的特殊物件才另挂白底道具图）。常规互动靠具体的支撑面与主词分工描述即可稳定生成，并能 100% 保留原设定图体态。
2. **后置构图／分镜参考（复杂空间与多人摆位选配，放人物与环境图之后）**：
   - **单格构图／姿势图**：用于多人复杂站位、特殊俯仰透视或镜面反射。出图后先检查肢体完整度，将可见人脸遮黑（嘴部接触处留出边缘；不露脸配角裁出画外）或转为白膜假人，身形比例尽量贴近原角色；提示词点名环境图的 2–3 个具体地标并声明忽略示意图背景。
   - **2–4 格分镜图（Storyboard Grid）**：仅用于同一段内需 `[Shot 1] → [Shot 2]` 连续切镜的走位设计（不宜超过 4 格，须搭配角色板保脸），提示词须明确对应各 Shot 切镜，防格线直接入画。
3. **前置精修首帧（要求起始画面完全锁死时选配，放最前）**：单镜需要像素级锁定开场构图时，简单姿态可直接用图像编辑模型将角色合入环境空镜；复杂多人姿态可「先文生图抓准姿势，再用编辑模型换入本片环境与角色」。完成后无须额外参考时直接用 `default` 跑首帧 I2V，需同时挂角色板稳住后续转身动态或挂 `<Audio N>` 时放 `ref` 的 `<Picture 1>`。

## 切镜（`shot`）与短链锚定接续（`context_anchor`）

以 `shot` 为稳健基底，并在同场戏善用 **2–3 段一组的短链 `context_anchor`** 增加拍摄手法。接续的本质是延续主体状态、构图关系与空间光影，不代表不能切镜，但须配合其底层机制（重绘上一段末尾 17 帧接缝，且前段重抽会让后续接续段变为 `stale`）：

- **短链分组，演完即断**：接续链控制在 2–3 段以内，一组演完就用 `shot` 切开（同时阻断画质飘移累积，重抽单段时也不会牵连整部长片；`upscale` 放大时同一接续链须按顺序或同批一起放大）。
- **善用 `context_anchor` 的时机**（同参考组合且前段末尾画面干净时）：
  - **低复杂度连续动作**：靠近、坐下、躺倒、轻抚到亲吻、余韵互动，或已稳定姿态的节奏延续，直接接续不硬切。
  - **同场运镜与段内切镜**：跨段开头先承接上一段末尾状态（避免在 17 帧重绘接缝处硬切造成画面融化），接着在段内做缓推近景、微调视角，或在段内用 `[Shot 2]` 切换反应近景；走入新空间或场景改变时标 `anchor: "restart"`。
- **直接用 `shot` 切开的时机**：更换参考图组合或服装阶段、跳过穿脱／对准等高变形过渡瞬间、大幅改变复杂交叠姿态，或前段末尾已出现轻微变形时。

## 长片分阶交付与高密度巡检

- **先 `single` 完片再 `upscale` 放大**：多段长片先跑 `single` 完成全片巡检与局部换 seed 重抽（遵守约定的生图与单段重抽上限），先合并保留一份 `single` 成品，再跑 `upscale` 另存高清合并版，不覆盖原档。
- **高风险段加密抽帧、逐张看原图**：秒数较长或含多人交叠、背面姿态、局部接触的段落，调高 `review_frames.py` 抽样密度与宽度（如 `--frames 6 --width 1536` 或 `--frames 9`），并**直接逐段查看各专案独立的原始检视图**，不把多段二次缩拼成小缩图总览；重点排查中段动态伸缩或分叉、背面姿态强行 180° 扭头、正面饰品反戴到背上，以及栏杆／窗台／床沿旁人物是否错站到墙外悬空侧。
