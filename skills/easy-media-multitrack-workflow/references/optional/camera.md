# 运镜与镜头

运镜的基本词汇见 [prompts/base.md](../prompts/base.md)「Camera Motion」，以下是补充。

## 写法

- 只写这个运镜用到的变量，其他的写成固定：推拉写焦距固定，横移写镜头朝向固定，升降写镜头保持水平；摇镜不提焦距。不写清楚，容易被读成别的运动。
- 变焦与推镜是两回事：变焦是机位不动、背景等比放大、透视不变（`the camera position stays fixed; the change comes entirely from zooming`）；推镜是机位前进、近大远小的差距变大。
- 画面里先出现的东西写在最前面：遮挡揭示先写前景的遮挡物，过肩先写近景的肩头，甩镜先写起手的那个东西。
- 摇镜给角度与落定：`pans right about 45 degrees and settles`。
- 一镜一个主运动，最多再加一个物理上连续的（推加仰）。
- 时间点会漂约 1 秒，一段内的切点常提前；动作的先后要用文字写清楚，不靠秒数卡。
- 环境写成一句「主体在什么地方」，不逐项点名柱子、地砖、灯；清单会把画面推宽。

## 难做的运镜

| 运镜 | 测试结果 | 写法要点 |
|---|---|---|
| 半环绕 180° | 成立 | 落点是正背面 |
| 整圈环绕 360° | 不挂 360 环绕类 LoRA 几乎回不到正面 | 圈数（转满一整圈、最后回到正面）与起止时间都写；不写「快速」，写了会多转 |
| 子弹时间 | 要 360 环绕类 LoRA | 先写时间凝结、发丝衣摆静止，再写环绕 |
| 翻滚 | 不稳定 | 写方向（顺／逆时针），中途要真的倒过来 |
| 希区柯克变焦 | 多半退化成普通推镜 | — |
| 急推变焦 | 有 Crash Zoom LoRA 较明显 | 写成突然的猛推，机位不动 |
| 甩镜 | 从物件甩到人物成功，从人物甩开失败 | 写起手物、甩的方向、落到谁身上、落定后的取景 |
| 荷兰角 | 只靠文字做不出倾角，要 Dutch Angle LoRA | — |
| 移焦 | 要写死从 A 到 B，两个不同深度的对象 | — |
| 过肩 | 最稳 | 先写近景的肩头，再写对面的人 |
| 正反打（一段内切） | 能切，切点常提前 1–2 秒 | 每句台词各在一边，不跨切点 |
| 推、拉、横移、升降、摇臂、顶拍、航拍、穿越、跟拍、斯坦尼康、视差 | 大多成立 | 横移、遮挡揭示的结束位置不稳定 |

要挂的 LoRA 照用户的 LoRA 说明档；说明档没写的不自己挂。

## 焦段与景深

- 24mm、35mm 广角：空间感与纵深，适合跟拍、一镜到底、过肩。
- 50mm：接近人眼。
- 100mm 长焦：压缩背景，像从远处窥看。
- 浅景深 `shallow depth of field, like the human eye`；深焦 `deep focus`；安静的近景可以 `gentle handheld stillness`。
