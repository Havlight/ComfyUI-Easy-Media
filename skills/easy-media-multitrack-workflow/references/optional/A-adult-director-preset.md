# 成人预设 A：景别机位、直白特写与全体位动作编排

适用代号：**预设 A（AV 预设 A）**。启用本预设时，凡涉及**摄影基调、景别与机位调度、体位时长配比与动作节奏层次**，以本文件覆盖 [craft.md](../craft.md) 与 [modules/type-adult.md](../modules/type-adult.md) 的通用默认排法；设定板、槽位隔离、直白词汇、接续与巡检照 [modules/type-adult.md](../modules/type-adult.md) 与 [SKILL.md](../../SKILL.md)，提示词格式照 [writing.md](../writing.md) 对应分页模型。

## 一、核心默认与基调收敛

- **视觉重心与现场实音默认**：
  - 画面焦点集中在女角表情与身体动态，女角对镜头与亲密互动默认为主动迎合、享受或挑逗；透过 POV、过肩或贴体取景让男方头脸自然退居画外或视野边缘（不硬性封死，依构图与参考素材自然处理；男方默认沉默或少台词，用户另指除外）。
  - 全程默认**无背景音乐**，聚焦近距离呼吸、喘息、吸吮口水声、肉体拍击水声与衣料摩擦等同步现场实音。
- **叙事比重与摄影基调锁定**：
  - *用户已给细目*：严格按用户指定的分镜、体位、剧情与运镜执行，仅补齐支撑面、精确景别与动作细节，不擅自加戏。
  - *用户给简短提示或交由规划*：默认采用**无铺陈直入或轻量情境破题（头尾约占 0–2 成；用户指定剧情脉络时依提示自然展开）**。动笔前选定本片的 **① 单一摄影质感基调（同片不混搭互斥设备感）**：
    1. **临场纪实手持（`Raw Gonzo / Handheld`）**：`24–35mm` 近距广角、环境自然光、轻微呼吸晃动，强化在场距离感与眼神直击；
    2. **唯美电影／写真稳定器（`Cinematic / Glamour Gimbal`）**：`35–85mm` 平滑运镜，搭配逆光轮廓、暗房单点暖光或霓虹色温雕琢湿润皮肤高光与浅景深，强化身体曲线与光影层次。
    随后选定 **② 互补机位组合** 与 **③ 核心体位及张力重点** 顺势延伸，全片维持统一摄影质感与光色温度。

## 二、景别标准、机位体系与直白特写

### 1. 景别选择标准（按当镜看点选最贴近的够用距离，不分上下半身、不无故拉远）
- **微距大特写（`ECU / Macro`，脸部出画）**：满框放大单一器官接触点、体液细节或手足抓握末端。
- **近景～中近景（`CU / MCU`，框住单一身体区块）**：
  - *拍上半身*：潮红脸庞、眼神转换、台词喘息、舌吻、口交吞吐；或**脸部出画专拍双乳弹跳晃动、抓揉指痕与乳交**。
  - *拍下半身（腰臀交合近景，脸部出画）*：框住小腹、撞击臀瓣肉浪与张开大腿根之间的肉棒抽插律动。
- **中景～大腿中段（`MS / Mid-Thigh`）**：同时装进脸胸与腰臀骨盆交合，呈现骑乘起伏、后入拱背、传教士或站立抽插的整体躯干联动（将易滑步的小腿脚掌留在画外）。
- **七分身～全身（`MFS / FS`）**：仅在画面重点包含整双腿部动作、全身轮廓或空间移动时拉开；多人交缠时不拉远成全身小人。

### 2. 三类机位视角（同场主体与互动延续优先用 `context_anchor` 衔接）
- **① 主观视角（`POV`）**：近身奉仕与交合的核心沉浸视角（可高比例或全程使用）——含男方俯视／平视／仰躺 POV（连带写出自身下腹、肉棒根部、大腿或扶头掐腰的手，可配单次 `Tilt Up / Tilt Down / Pull-Close` 或多人 `Gaze Pan`），以及女方低头主观 POV（越过自己晃动双乳往下看腿间抽插或自慰）。
- **② 贴身第三人称视角（聚焦女角的外部镜头）**：
  - *随动跟拍*：女角移动、转身或蹲跪躺倒时，保持贴近距离平移跟随、推进（`Push In`）、随身体重心同步升降（`Pedestal Up / Down`，区别于机位不动仅原地低头的 `Tilt Down`），或由裙底低角度往上跟拍。
  - *交合贴体角度*：斜上俯拍（女脸与双乳占主画面，延伸带出腰臀抽插）、侧面／斜侧面拍（拱背塌腰曲线与撞击臀浪）、**双腿间／跨下低角度仰拍**（由下往上同时拍清肉棒进出阴户或口腔、晃动双乳与面部表情）、趴姿女脸贴床前景带出后方扶臀猛干、过肩视角（`OTS`）。
- **③ 镜面、贴玻璃与遮挡构图（按场景选配）**：背后抽插配前方全身镜／洗手台镜映出潮红正脸与晃乳（`Mirror Dual-View`）；双乳或屁股死压透明落地窗／浴室玻璃挤压变形（`pressed flush against glass`）；微开门缝、百叶窗光影切割或隔桌框景（含**台面上装镇定对话／接电话 × 台面下偷偷含肉棒或被插的上下分割构图 `Stealth Split`**）。

### 3. 四大直白特写与主动展示（供各体位穿插放大刺激）
- **性器抽插交合特写**：硬挺肉棒滑入／猛插湿透分开的阴唇或紧缩菊穴，清晰呈现阴唇包覆拉扯、透明淫水／白浊拉丝与耻骨拍击臀根。
- **口乳手足奉仕特写**：双唇紧吸湿亮肉棒与伞状龟头、舌尖舔弄冠状沟与马眼、油亮双乳夹紧肉棒套弄、手指掰开阴唇抠弄阴蒂穴口、丝袜足弓夹搓肉棒。
- **乳臀肉感与末端张力特写**：随猛烈抽送上下弹跳的奶子、大手抓揉乳肉陷下的指痕、撞击泛起波纹的屁股、死抓床单泛白的手指与绷直蜷曲的脚趾。
- **主动掰开与事后溢精展示**：停顿、转身或拔出节点，女角**亲手掰开两瓣屁股或湿亮阴唇对准镜头、拎起拉丝的半褪湿内裤，或将射满精液的舌头／奶子凑近镜头展示**；内射拔出后可单拍**浓稠精液从微张穴口缓缓涌出滴落、大腿内侧微抽搐**的特写。

## 三、场次时长、跨段延续与起承转合

- **以多段连贯展开为单位（善用 `context_anchor`，避免一段换一姿势）**：
  - *跨段展开与重点拉长*：实质奉仕或做爱体位默认用 `context_anchor` 跨多段完整展开，不切成单段闪过；片长较短时直接减少体位数量（甚至整支专注拍透单一体位），片长充裕时不必各场次等长均分，可依看点与高潮自由将重点场次拉得更长。
  - *同场跨段的「持续 vs. 变化」*：用 `context_anchor` 延续人物与空间光影时，镜头既可**维持同机位连续拍下去**，也可**跨段／段内切入小穴抽插、奶子晃动特写或换互补角度**；动作既可**维持同一抽插／含吮节奏连续干上数段**（靠持续律动与喘息失控累积爽感，不强求每段改姿势），也可在演足后**阶段性转换快慢深浅或身体倾角**。
  - *单段秒数疏密*：持续律动、跟拍或寸止蓄力可用较长秒数（`7–10s`）；局部特写或高潮冲刺快切可缩短秒数（`3–5s` 或段内 `[Shot 2]` 切镜）。
- **地形高低差借力**：依场景自由搭配立面（压墙、贴窗挤压、扶镜折腰）、中高度台面（压桌后入、跨坐桌沿、台面上下隐秘分割）、坐具（正／逆坐姿骑乘、面对面跨坐抱操、沙发旁深蹲跪姿）与床沿／床面高低差，不套固定换房顺序。
- **轻量破题与收尾选单**：开场可直入正戏，或用动态观察、一两句自答台词、主动掀裙开领破题；片尾可选**内射溢精微痉挛余韵**或**整理微乱衣裙对镜微笑道别的日常复位**。

## 四、全体位动作演进、视线与声画层次

各段保持**重力支撑面与核心耦合基底稳定**，跨段或单段内组合以下变化层次：

1. **全体位重心与动作演进（均衡覆盖各体位家族）**：
   - *女上位骑乘*：直立挺胸上下弹跳 ↔ 俯身贴胸拥吻前后磨蹭 ↔ 双手后撑仰头弓腰猛摇 ／ 背对镜头逆骑乘看屁股套弄与回头斜看；
   - *后入与趴卧*：四肢着地扶腰猛干 ↔ 塌腰脸埋枕头翘高屁股深插 ↔ 完全趴平夹紧双腿全压抽送（`Prone Bone`） ／ 压桌扶墙站立后入；
   - *仰卧与面对面*：平躺分腿传教士 ↔ 双腿抬高架肩深插 ↔ 抱紧大腿根折叠种付猛干（`Mating Press`） ／ 面对面坐姿抱操；
   - *前戏与奉仕*：深吻拉丝、揉胸抠穴、口交（舔冠状沟 ↔ 浅含配手套弄 ↔ 按头深喉喉部微隆 ↔ 吐出拉丝将湿肉棒贴潮红脸颊或奶子磨蹭）、双乳夹挤乳交、丝袜足交、大腿根素股磨蹭；插入抽送亦可在穴口浅磨寸止、全幅拉出重顶与贴死耻骨深处旋转研磨之间切换。
2. **速率波形、中途定格与峰值慢动作**：
   - 交替慢速深磨、渐进加速猛干与**中途突然停住定格**（如整根顶到最深处完全不动仅留急促喘息与小腹微颤、骑乘沉腰坐死停顿、或含住龟头前端不动数秒）。
   - 遇甩发、掀裙、重击屁股与奶子剧烈弹跳波纹、腾空动作或潮吹喷水／射精喷发瞬间，可单独切出一段 `Slow-motion` 高格率慢动作放大肉感惯性（前后段维持常速，不在同段内混写变速）。
3. **空闲手脚的次要表现**：
   - 口部或下身维持插入／含覆时，空出的手脚可搭配加分细节：双手托挤自己双乳、十指紧扣压床、反手扶开自己臀瓣、由双膝跪地微起身改单膝支撑换角度、对镜头眨眼／比手势／触镜、边被干边滑手机／扶正滑落眼镜（日常错位），或双手捂嘴憋住呻吟。
4. **视线转换（「先不看镜头，之后再看镜头」）与半脱衣妆累积**：
   - 避免整段僵硬死盯镜头——安排**先不看镜头**（先低头看肉棒进出结合处、闭眼仰头承受快感、看着伴侣接吻或害羞撇头），**随后再转眼或抬眼直视镜头**（视线高低匹配机位：俯拍配仰视、仰拍配垂眸俯视、背身配回头斜看）。
   - 不必开场即全裸，善用半脱状态直接实战（咬住掀起的衣服下摆露奶、不脱内裤直接拨开档部布料插入 `panties pulled aside`、保留制服裙摆与丝袜高跟）；跨段逐步叠加胸颈潮红、薄汗高光、湿发贴脸、口红微花与大腿内侧淫水精液残留。
5. **台词调性与声画反差**：
   - 口部空闲给对嘴 `<d>` 直白台词，口部含着肉棒、深吻或背身忍耐时可改用**闭嘴气声内心独白（`says in an off-screen voiceover: <d>…</d> while her lips remain…`）**，语气可选饥渴索求、温顺讨好汇报或表面冷静日常叮嘱；偷情或隐秘场景可在环境音写入门外日常声／通话声，对比近处压抑喘息与抽插水声。
