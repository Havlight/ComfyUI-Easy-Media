# 成人叙事、伪纪实视角与空间编排

在 [craft.md](../craft.md)、[modules/type-adult.md](../modules/type-adult.md) 与 [optional/ref-sheets-and-longform.md](ref-sheets-and-longform.md) 基础上，提供从开场带入亲密正戏的叙事构思与场面调度原则。固定底层默认生效；可选菜单与段落比重由用户指定，或由 Agent 依题目与片长自由组合。

## 固定底层原则

- **男角全程不露脸，视觉聚焦女角**：无论单男或多男，男角五官一律不入镜——采用 ① 侧后方过肩拍（近景仅带到男角后脑勺、侧颈或肩膀轮廓，对面完整拍出女角正脸与正面曲线）、② 画框裁切（上缘裁在男角下巴或胸口以下）、或 ③ 局部入画（仅腰腹、大腿根部与手臂入镜）。
- **女声单向主导，男方沉默**：全片 `<d>` 台词与喘息均由女角发声（排在口部空闲的近景或展示镜）；男角与掌镜者全程保持沉默，不排 `<d>` 台词。
- **知情配合与主动享乐（去抗拒化）**：女角对镜头拍摄与亲密行为皆为认可、主动配合或乐在其中，不写「不要拍、停下来、遮脸推拒」等抗拒台词与动作。
- **「伪 POV／伪纪实」不锁死机位**：开场、说话与展示段可用主观对视或跟拍感建立带入感；进入正戏后自由混用 `craft.md` 与 `type-adult.md` 的标准切镜（胸上表情近景 ↔ 脸部出画局部特写 ↔ 侧面／背后中景），并在第三人称镜头中适时穿插女角「转头直视镜头微笑」以维持被拍摄的临场感。画质与光影保持清晰稳定，不刻意写失焦、剧烈晃动或模糊噪点。

## 可选叙事与演出菜单（按需组合）

### 1. 开场切入方式

- **日常观察转场**：前段以随机旁观视角（不解释掌镜者身份）拍女角在日常职场、门市或居家的正常工作与生活状态；随后直接切换视角与空间进入私密互动，省略繁琐的移动交接过程。
- **剧集式自答破题**：直接从私密空间、等待或前戏准备开拍；掌镜者不发问，由女角对着镜头（或场内男角）用一两句回应式或叮嘱式自然台词点破背景与前因（如瞒着伴侣外出、秘密约定、主仆指令或利益交换）。
- **服装微破绽直入**：开场女角穿着端庄制服或日常服对镜头微笑，随即主动掀开裙摆一角或拉开领口，向镜头展示内搭的情趣衣袜或配件，配一句简短台词直接切入正戏。

### 2. 女角人设与台词调性

- **饥渴痴女（主动索求）**：眼神自信勾人，主动引导动作与跨坐节奏；口部空闲时的台词偏向挑逗、展示技巧与主动索求。
- **温顺臣服（奉仕抖 M）**：姿态谦卑顺从（跪姿仰视、双手奉上、听令摆姿）；台词偏向温顺请示（「这样速度可以吗」、「接下来怎么服侍」）、汇报身体感受与感谢赐予。
- **端庄假面（日常错位）**：表面维持专业、冷静或贤慧语气，甚至在亲密互动中穿插日常琐事叮嘱（「别弄脏等下要穿的制服」、「快一点要来不及了」），身体动作却熟练迎合。

### 3. 镜头在场关系

- **伪 POV（掌镜者即参与者）**：镜头代表正在被女角服侍的对象；女角直接对镜头说话、靠近奉仕，正戏穿插主观俯仰角与客观特写。
- **伪纪录片（默许驻场跟拍）**：镜头代表在场被默许的摄影师（如贴身取材或私密记录）；女角一边与场内不露脸男角互动，一边对镜头回答问题、摆姿势或转头对视。

### 4. 前奏展示与收尾闭环

- **战前全身诱惑展示**：进入实质接触前可排单人诱惑镜——中全景拍半解制服或情趣衣袜下的大轮廓动态（转身扭臀摆胯、坐床沿伸展或微张双腿、手撩裙摆）；胸上中近景拍对镜头微笑、眨眼或比 V（Ya 手势）。
- **事后日常复位收尾**：片尾可拍女角带着事后微乱发丝与潮红，神色自若地整理衣裙、戴回配件并对镜头微笑道别准备走回日常，强化反差闭环。

## 空间转移与家具体位编排

- **同场所跨区域推进**：中长片不必频繁更换大场景，可在同一场所的不同功能区之间推进动线（如客厅沙发 → 厨房餐桌 → 阳台落地窗 → 卧室床铺；或办公桌 → 会议室 → 窗边），每换一区自然带来新的光影与背景纵深。
- **依家具地形匹配体位**：充分利用当前区域的家具结构，避免全片局限在床上：
  - **立面（墙面、落地窗、门板、镜面）**：站立压墙、单腿抬起、正面贴窗挤压、扶墙折腰。
  - **中高度台面（书桌、办公桌、餐桌、中岛、洗手台、栏杆）**：俯趴压桌后入、坐姿跨坐桌沿、双手撑台面迎合。
  - **坐具（办公椅、单人椅、沙发）**：正／背面坐姿女上位骑乘、跨坐大腿面对面、跪在沙发旁奉仕。
  - **低平面（地板地毯、榻榻米、床沿、床垫）**：地板跪伏奉仕、床沿站跪高低差、仰卧／侧卧／趴姿全压。

## 叙事比重与分章推进参考

开头铺陈与收尾尽量精简（合占全片约 1–2 成），将主要篇幅（8 成以上）留给奉仕与多阶段体位正戏。篇幅较长时可按阶段拆分为多个子专案（各阶段可依用户要求或片长自由伸缩、合并或略过），并随阶段切换角色服装设定图（见 `type-adult.md`）与区域家具：

1. **日常破题与诱惑展示（短铺陈，可略过）**：开场切入（观察转场／自答破题／微破绽）→ 战前全身曲线与近景手势诱惑 *(完整穿衣板，后段可切半脱板)*。
2. **近身挑逗与主动奉仕**：在第一区域（如沙发前、桌下或床沿）进行半脱爱抚与跪姿口／手／胸奉仕，穿插口部空闲时的请示或反差台词 *(半脱设定板 + 男角遮脸躯干板)*。
3. **主体位展开与臣服互动（核心正戏）**：结合当前家具（椅子坐姿骑乘、沙发或床铺交合）展开核心互动，交替切胸上表情台词镜、局部接触特写与后脑过肩中景 *(裸体留袜鞋设定板)*。
4. **跨区换场与高张力／多人升级（核心正戏，长片可拆多章）**：移至新区域（落地窗、餐桌、阳台、卧室）切换高张力家具体位，或升级为多名不露脸男角左右非对称包围服侍。
5. **冲刺、余韵与日常复位（短收尾）**：密集冲刺与高潮反应 → 平静余韵残留 → 整理衣着回归日常的对镜道别。
